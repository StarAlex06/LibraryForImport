# Table Importer

Python-библиотека для сканирования и импорта табличных данных из CSV-файлов, Excel-таблиц и баз данных SQLite.

## Возможности

- Поддержка форматов CSV, XLSX и SQLite.
- Сканирование источников данных с получением метаданных о листах и таблицах.
- Определение предполагаемых типов данных столбцов и количества пропущенных значений.
- Импорт данных частями с настраиваемым размером блока.
- Приостановка и возобновление процесса импорта.
- Преобразование типов данных столбцов.
- Отслеживание прогресса импорта с помощью callback-функции.
- Единый интерфейс для работы с различными источниками данных.
- Возможность регистрации новых типов источников.
- Собственные исключения для обработки ошибок.

## Требования

- Python 3.11 или новее.
- pandas.
- openpyxl.

## Быстрый старт

```python
from table_importer import TableImporter

importer = TableImporter()

# Получение метаданных об источнике
metadata = importer.scan("data.csv", sample_size=1000)

print(metadata.name)
print(metadata.row_count)
print(metadata.column_count)

for column in metadata.columns:
    print(column.name, column.data_type, column.missing_count)

# Импорт данных
df = importer.import_data(
    "data.csv",
    chunk_size=10000,
)

print(df.head())
```

Аналогичный интерфейс используется для работы с поддерживаемыми файлами Excel и базами данных SQLite.

## Сессии импорта

Для более гибкого управления процессом импорта можно создать сессию:

```python
from table_importer import TableImporter

importer = TableImporter()

session = importer.create_session(
    "data.csv",
    chunk_size=1000,
)

# Чтение очередного блока данных
first_chunk = session.read_next_chunk()

# Приостановка и возобновление импорта
session.pause()
session.resume()

# Чтение оставшихся блоков
while not session.is_finished:
    session.read_next_chunk()

# Получение итогового DataFrame
result = session.get_result()
```

Сессия позволяет читать данные отдельными блоками, а не загружать весь источник за один шаг. Прочитанные блоки сохраняются внутри сессии и объединяются в один объект `pandas.DataFrame` при вызове `get_result()`.

## Преобразование типов и отслеживание прогресса

При создании сессии можно указать типы данных столбцов и функцию обратного вызова для отслеживания прогресса:

```python
from table_importer import TableImporter

importer = TableImporter()

session = importer.create_session(
    "data.csv",
    chunk_size=1000,
    dtype={"id": "int64"},
    progress_callback=lambda rows: print(f"Импортировано строк: {rows}"),
)
```

Параметр `dtype` задаёт требуемые типы данных в формате, поддерживаемом pandas. Функция `progress_callback` получает количество строк, обработанных к текущему моменту.

## Метаданные

Метод `scan()` возвращает метаданные каждого листа или таблицы, включая:

- Название листа или таблицы.
- Количество строк, если оно доступно.
- Количество столбцов.
- Предполагаемые типы данных столбцов.
- Количество пропущенных значений.
- Количество строк, фактически просмотренных при сканировании.
- Признаки точности количества строк и количества пропусков.

Для ускорения работы с большими источниками метаданные могут вычисляться по выборке данных, а не по всему набору. В таком случае соответствующие признаки точности показывают, что полученные значения не гарантированно точны.

## Исключения

Библиотека определяет базовое исключение `TableImporterError` и специализированные исключения:

- `SourceNotFoundError` — источник данных не найден.
- `UnsupportedFormatError` — формат не поддерживается.
- `SheetNotFoundError` — лист или таблица не найдены.
- `ScanError` — ошибка при сканировании источника.
- `DataImportError` — ошибка при импорте данных.
- `TypeConversionError` — ошибка преобразования типов.
- `ImportStateError` — недопустимое состояние сессии импорта.
